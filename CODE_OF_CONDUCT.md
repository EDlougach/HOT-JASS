# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for everyone taking part in its issues, pull
requests, discussions and other project spaces.

In short: be respectful and constructive, welcome people of every background
and level of experience, criticise ideas and code rather than people, and
accept that the maintainer decides what is merged. Harassment, insults and
personal attacks are not tolerated.

## Reporting

Report unacceptable behaviour privately to the maintainer, Eugenia Dlougach,
at **edlougach@gmail.com**. Reports are treated confidentially. The
maintainer may remove, edit or reject comments, commits, code and issues
that break this code of conduct, and may ban contributors who repeatedly or
seriously break it, following the enforcement guidelines of the Contributor
Covenant.
